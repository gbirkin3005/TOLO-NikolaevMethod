# TOLO — Расчёт напряжений и деформаций при лазерной обработке

Программа для расчёта продольных деформаций и напряжений при лазерной сварке
(и наплавке на кромку) **графоаналитическим методом Г.А. Николаева**.
Выполнена в рамках домашнего задания по курсу «Теоретические основы лазерной
обработки» (МГТУ им. Н.Э. Баумана, кафедра МТ12).

Приложение Windows Forms на **C# / .NET 10**: рассчитывает квазистационарное
температурное поле подвижного линейного источника теплоты, строит изотермы и
эпюры деформаций/напряжений, а также формирует готовый отчёт в формате Word.

## Возможности

- **Расчёт температурного поля** от подвижного линейного источника (лазерная
  сварка с полным проплавлением) с использованием функции Бесселя `K₀`.
- **Распределение температуры** по поперечной (`x = 0`) и продольной (`y = 0`)
  осям с таблицами значений.
- **Определение изотерм** 500 °C и 600 °C (координаты точек) и размеров зоны
  разогрева.
- **Эпюры деформаций и напряжений** по методу Николаева:
  - стадия нагрева (сжатие в зоне шва);
  - после полного остывания (остаточные напряжения; в шве — растяжение ≈ σт).
- **Тепловая карта изотерм** с автоматическим масштабированием под тепловое
  поле, сглаживанием и точными изотермами-кривыми.
- **Два режима**: сварка встык (условие равновесия сил `∫σ dy = 0`) и наплавка
  на кромку (дополнительно равновесие моментов `∫σ·y dy = 0`).
- **Материалы**: низкоуглеродистая сталь, нержавеющая сталь, алюминиевый сплав,
  титановый сплав (либо ручной ввод теплофизических свойств).
- **Отчёт Word (.docx)** с техническим заданием, ходом решения, формулами
  (объекты Office Math / OMML), таблицами (до 30 значений) и графиками — без
  установленного Microsoft Word.
- **Экспорт** данных в Excel (`.xlsx`) и результатов в текстовый файл.
- **Сохранение/загрузка** введённых параметров (JSON) через верхнее меню.
- **Адаптивная компоновка** окон — содержимое растягивается при изменении
  размеров окна.

## Теоретическая основа

**Температурное поле** подвижного линейного источника:

```
T(x, y) = q / (2π·λт·δ) · exp(−vсв·x / (2a)) · K₀( (vсв/(2a))·√(1 + 4ba/vсв²) · r )
```

где `r = √(x² + y²)`, `b = 2αт/(Cγ·δ)` — коэффициент температуроотдачи,
`K₀` — модифицированная функция Бесселя 2-го рода.

**Метод Николаева** (стадия нагрева):

- свободная температурная деформация `εt = αT`;
- условие совместности (гипотеза плоских сечений): `εупр + εпл = εн − αT`;
- напряжение `σ = E·εупр`, ограниченное пределом текучести `σт(T)`:
  - `σт = const` при `T ≤ 500 °C`,
  - линейно убывает до нуля на `500…600 °C`,
  - `σт = 0` при `T ≥ 600 °C`;
- положение линии наблюдаемой деформации `εн` подбирается из условия
  равновесия `∫σ dy = 0` методом последовательных приближений.

После остывания накопленная пластическая деформация укорочения даёт остаточные
напряжения, которые в зоне шва близки к пределу текучести.

## Требования

- **Запуск собранной версии:** Windows x64. Self-contained сборка не требует
  установленного .NET; framework-dependent сборка требует
  **.NET 10 Desktop Runtime**.
- **Сборка из исходников:** .NET 10 SDK (Visual Studio 2022/2026 или CLI).

## Сборка и запуск

```bash
# восстановление зависимостей и запуск
dotnet run --project "TOLO ver 2.csproj"

# сборка автономного дистрибутива (один .exe, без установки .NET)
dotnet publish "TOLO ver 2.csproj" -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

Готовый исполняемый файл — в `bin/Release/net10.0-windows/win-x64/publish/`.

## Использование

1. Выберите материал (или включите ручной ввод свойств).
2. Задайте параметры пластин и режима сварки (толщина, ширины `B₁`/`B₂`,
   скорость, мощность), а также границы расчёта и число точек.
3. Нажмите **«Рассчитать»** — программа вычислит температурное поле,
   изотермы, деформации и напряжения.
4. **«Показать графики»** — окно с эпюрами и тепловой картой изотерм.
5. **«Создать отчёт Word»** (в окне графиков) — сформирует `.docx`.
6. При необходимости — экспорт таблиц в Excel и результатов в текст.
7. Меню **«Сохранить/Открыть параметры»** — сохранение исходных данных в JSON.
